# 졸업작품 - 자동화 이송 및 분류 시스템

## 1. 프로젝트 개요

한국폴리텍대학에서 진행한 졸업작품 프로젝트입니다.

본 프로젝트는 제품을 자동으로 **승강 → 이송 → 전달 → 집게를 이용한 파지 → 분류 및 적재**하는 자동화 시스템을 구성하는 것을 목표로 진행했습니다.

전체 시스템의 기계 구조를 설계하고, 각 장치의 조립 및 작동을 고려하여 주요 부품을 3D CAD로 모델링했습니다.

---

## 2. 전체 공정

전체 장비의 공정은 다음과 같이 구성됩니다.

```text
리프트
  ↓
로봇 팔
  ↓
컨베이어
  ↓
서보모터 + 집게
  ↓
분류대 및 적재
```

각 장치는 서로 연결되어 제품이 다음 공정으로 이동하고 최종적으로 지정된 위치에 분류 및 적재될 수 있도록 구성했습니다.

# 3. 주요 시스템 구성

## 3-1. 리프트 (Lift)

제품을 지정된 높이까지 이동시키고 다음 공정인 로봇 팔로 전달하기 위한 승강 장치입니다.

리프트의 프레임과 구동 구조를 설계하고, 제품의 이동 과정에서 안정적으로 승강할 수 있도록 구조를 검토했습니다.

또한 리프트를 구성하는 각 부품의 결합 관계와 전체 장비와의 연결 구조를 고려하여 3D 모델링을 진행했습니다.

| Sensor Holder   | 센서 고정        |
| END_OF_CONVEYOR | 컨베이어 끝단 구조   |
| Bridge Leg      | 장비 연결 및 지지   |
| Leg             | 장비 하부 지지     |

# 10. 프로젝트를 통해 배운 점

이번 프로젝트를 통해 단순한 기계 부품의 모델링뿐만 아니라 여러 장치가 연결된 자동화 시스템의 구조를 설계하는 과정을 경험했습니다.

특히 **리프트, 로봇 팔, 컨베이어, 서보모터 및 집게, 분류대**가 하나의 공정으로 연결되는 과정을 통해 개별 부품의 설계뿐만 아니라 장비 전체의 배치와 조립 관계를 함께 고려하는 것이 중요하다는 점을 배웠습니다.

또한 3D CAD 모델링과 2D 도면 작성, 조립 구조 검토 및 실제 제작 과정에 참여하면서 설계가 실제 장비로 구현되는 과정을 경험했습니다.
