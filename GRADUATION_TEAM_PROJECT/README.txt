# 🤖 졸업작품: 자동화 이송 및 분류 시스템
> **승강(Lift) → 로봇 팔(Robot Arm) → 컨베이어(Conveyor) → 집게(Gripper) → 분류 및 적재(Sorting & Loading)**로 연결되는 스마트 자동화 공정 기계 설계 및 3D/2D CAD 포트폴리오입니다.

## 1. 📌 프로젝트 개요

한국폴리텍대학 졸업작품으로 진행한 **스마트 자동화 이송 및 분류 시스템** 프로젝트입니다.

제품을 자동으로 **승강 → 이송 → 전달 → 파지 → 분류 및 적재**하는 메카니즘을 구성하는 것을 목표로 하였습니다. 전체 시스템의 기계 구조를 설계하고, 각 장치의 조립성 및 작동 간섭을 고려하여 주요 부품을 3D CAD(Inventor) 및 2D CAD(AutoCAD)로 모델링했습니다.
